Koneksi GitHub

Dengan koneksi ini, tombol “Simpan frame ke daftar”, edit, dan hapus langsung diterapkan ke website tanpa upload manual. Cukup diisi sekali di perangkat ini.

Cara membuat token (sekali saja)
  1. Buka github.com, klik foto profil, lalu Settings, Developer settings (paling bawah), Personal access tokens, Fine-grained tokens, Generate new token.
  2. Token name: photobooth-admin. Expiration: pilih masa berlaku (misalnya 1 tahun).
  3. Resource owner: pilih akun/organisasi pemilik repo.
  4. Repository access: Only select repositories, lalu pilih repo photobooth-mu.
  5. Permissions, Repository permissions, Contents: pilih Read and write.
  6. Klik Generate token, salin tokennya (hanya tampil sekali), lalu tempel di kolom Token di bawah.

Jika repo milik organisasi, owner organisasi mungkin perlu menyetujui token tersebut. Token disimpan di browser perangkat ini saja, jadi hanya isi di perangkat pribadimu.

Cadangan manual (opsional)

Jika koneksi GitHub aktif, frame otomatis tersimpan ke website dan langkah ini tidak diperlukan. Pakai hanya sebagai cadangan, atau saat belum terhubung.

  1. Klik Unduh paket (ZIP).
  2. Ekstrak, lalu salin folder frames/ ke folder proyek (timpa frames.json).
  3. Commit & push ke GitHub. Tunggu sekitar 1 menit sampai GitHub Pages ter-update.
